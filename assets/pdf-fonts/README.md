# Fontes dos relatórios PDF

Noto Sans 2.015, pesos Regular e Bold, TTF unhinted sem alteração, distribuídos
sob SIL Open Font License 1.1 em [OFL.txt](OFL.txt). A aplicação incorpora subsets
no PDF; não depende de fontes instaladas no cliente nem busca fontes pela rede.

Origem: [release oficial NotoSans-v2.015](https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSans-v2.015).
Arquivo de distribuição: `NotoSans-v2.015.zip`.
Entradas extraídas: `NotoSans/unhinted/ttf/NotoSans-Regular.ttf`,
`NotoSans/unhinted/ttf/NotoSans-Bold.ttf` e `OFL.txt`.
