The original PNG portraits, WebP atlases and pet.json files are unmodified.

These are community Pets, not official OpenAI Dots or a connection to ChatGPT.
The atlas is v2, 1536 x 2288, 8 columns x 11 rows; each cell is 192 x 208.
The console preview shows the first seven idle frames only, not live task status.
The console can save the separate PNG portrait through the normal icon workflow.

To install in a compatible desktop app, extract this package into a separate
pet folder and select it in the app's Pets settings. Keep pet.json beside
spritesheet.webp. Check the format accepted by your installed app first.
Some ChatGPT web clients document a 1536 x 1872 atlas; this package is v2 and
must not be uploaded to a client that requires the older dimensions.
No installer or executable is included. Installation is a separate user action.
