# Mapeamento de erros

Envelope das tools:

```json
{
  "success": false,
  "error": {
    "code": "PERMISSION_DENIED",
    "message": "O client_token não cobre uma ou mais tabelas deste SQL.",
    "hint": "Peça um client_token que inclua essas tabelas.",
    "retryable": false,
    "retryAfterMs": null,
    "source": "client_token_rpc",
    "stage": "sql.execute",
    "category": "access",
    "nextAction": "verificar_acesso",
    "documentationUrl": "https://mcp.se7esistemassinop.com.br/docs/mcp/error-mapping.md#permission_denied"
  }
}
```

Não vaze stack, SQL interno do MCP, senha, `client_token` ou token MCP.

## Hub / RPC

| Origem                        | `code`                                      | hint típico                                                                                                                                                                  |
| ----------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JSON-RPC `-32001`             | `MISSING_CLIENT_TOKEN`                      | Configure o `client_token` no acesso.                                                                                                                                        |
| `-32002` + "classification"   | `INVALID_SQL`                               | Agente não classificou o SQL. Conferir FROM e o dialeto (`atualizar_dialeto` se for SQL Server). Não é token revogado. O hint de `consultar_dados` cita as tabelas enviadas. |
| `-32002` (sem classification) | `ACCESS_REVOKED`                            | client_token revogado ou sem permissão.                                                                                                                                      |
| JSON-RPC `-32009`             | `INVALID_SQL`                               | SQL recusado pelo dialeto do agente.                                                                                                                                         |
| HTTP 403 Client inativo       | `CLIENT_NOT_ACTIVE` / `AGENT_ACCESS_DENIED` | Ativar o Client; **não** tratar como senha errada.                                                                                                                           |
| HTTP 429                      | `RATE_LIMITED`                              | `Retry-After`.                                                                                                                                                               |
| HTTP 503                      | `AGENT_UNAVAILABLE`                         | Agente offline; retry.                                                                                                                                                       |
| HTTP 401                      | `USER_AUTH_EXPIRED`                         | `withHubAuth` invalida o JWT, reloga e **repete a operação uma vez**. Se a senha do cofre falhar: `CREDENTIAL_STALE`.                                                        |
| abort HTTP                    | `PLUG_SERVER_TIMEOUT`                       | Retryable.                                                                                                                                                                   |
| JSON-RPC `-32008`             | `QUERY_TIMEOUT`                             | Query estourou o timeout do agente; retry ou reduza o SQL.                                                                                                                   |
| HTTP 5xx / RPC genérico       | `PLUG_SERVER_ERROR`                         | Falha no hub; veja hint. Retry se `retryable`.                                                                                                                               |

| `ALIAS_DESCONHECIDO`                     | Qualificador de coluna/JOIN não resolve para FROM/JOIN deste SELECT                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

| `CONFLICT`                               | Acesso/skill duplicado; rename de `slug` colide com unique `(agent_id, slug)`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `CREDENTIAL_STALE`                       | Senha do Client no cofre recusada no login (depois do 401 + retry)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `PERMISSION_DENIED`                      | Policy do `client_token`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `USER_AUTH_EXPIRED`                      | JWT do Client recusado mesmo após o retry único de `withHubAuth`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `INVALID_SQL`                            | `SELECT *` (também aninhado) em treino/consulta, mutação, segundo comando, expressão sem AS, coluna sem qualificador em JOIN, JOIN sem igualdade no `ON`; SQL que o plug_agente não classifica (`-32002` + classification) — não é token revogado. `inspecionar_consulta` **não** executa estrela crua: expande colunas conhecidas do pacote.                                                                                                                                                                                                                                                                                                                 |
| `SKILL_NOT_FOUND` / `ANOTACAO_NOT_FOUND` | Id inexistente neste `agentId`. | `TABELA_FORA_DO_ESCOPO`                  | SQL da IA cita tabela fora do pacote publicado, ou `descobrir_tabela` pediu tabela que não está em skill publicada. | `COLUNA_FORA_DO_ESCOPO`                  | Coluna fora do catálogo da tabela no escopo, ou métrica/dimensão/filtro de `consultaSemantica` não certificado em `metricasSaida`/`graoResultado`, ou overlay de KPI (`criar_skill`/`atualizar_skill`/`registrar_aprendizado` tipo=metrica) com alias/expr inventado. | `FANOUT_NAO_DECLARADO`                   | Agregação financeira com JOIN N:N ou sem cardinalidade no recorte organizacional — também no `sqlModelo` / `skill_*`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `FEATURE_DESLIGADA`                      | Tool nova atrás de flag (`MCP_INSPECTION_ENABLED`, `MCP_DISCOVERY_QUERY_ENABLED`, `MCP_SEMANTIC_QUERY_ENABLED`, `MCP_SCHEMA_DRIFT_ENABLED`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `OPERACAO_CANCELADA`                     | Perfilamento/descoberta cancelado com `cancelar_operacao`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `SCHEMA_DRIFT`                           | Código reservado. `detectar_deriva_esquema` **não lança** este erro: devolve `success` + `drifted` e move só as skills da tabela para `rascunho_revalidacao`. | `PRIVACIDADE_NEGADA`                     | `consultar_dados` projeta `segredo` (sempre, inclusive agregado) ou `pessoal` (exceto `COUNT`) em SELECT. `inspecionar_consulta` recusa só `segredo`; pessoal/sensível seguem mascarados. Sem `finalidade` → `VALIDATION_ERROR`.                                                                                                                                                                                                                                                                                                                                                                |
| `CONSULTA_ORCAMENTO`                     | `max_rows`, tabelas ou detalhe sem recorte temporal acima de `politicaConsulta` da skill (teto global `QUERY_*` continua). Inspeção permanece teto 100.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `PERFIL_AUSENTE`                         | Pacote incompleto para publicar (tipo/formato/cardinalidade, inclusive tipo incompatível com o papel). | `CONSULTA_SEM_RECORTE`                   | SQL livre sem WHERE e sem agregação (janela `OVER` conta como agregação)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `ESCOPO_FILTRO_AUSENTE`                  | Acesso tem empresa/filial default e o SQL não recorta a coluna correspondente                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `RATE_LIMITED`                           | Teto HTTP ou por tool                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `QUERY_TIMEOUT`                          | Timeout da query no agente                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `PLUG_SERVER_ERROR`                      | Erro genérico do hub                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `INTERNAL_ERROR`                         | Falha inesperada no MCP                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

Avisos (não são throw): `LITERAL_TEXTO` (literal em WHERE/HAVING — prefira `:param`), `PLACEHOLDER_ESCOPO` (grafo tem coluna empresa/filial e o SQL não usa `:empresa`/`:filial`), `PERFIL_QUERY_FALHOU` / `PERFIL_TETO` no treino/validação completo, `CATALOGO_TIPOS_AMBIGUOS` em `mapear_tabela`, `PERFIL_AUSENTE` em `obter_skill`/`skill://`, `CACHE` (dataDoResultado vs servidoEm), `INSPECAO` (amostra mascarada; não use para KPI), `CONSULTA_SEMANTICA` (SQL compilado dos elementos certificados), `KPI_DESALINHADO` (SQL livre omite status/data do KPI), `SCHEMA_DRIFT` (payload de treino/mapeamento; não throw).

Campos opcionais do envelope (`source`, `stage`, `category`, `nextAction`, `documentationUrl`, `details`) vêm do mapa em `error-next-action.ts`. `ACCESS_REVOKED` com `source: client_agent_access` → `verificar_acesso`; com `source: client_token_rpc` → `atualizar_credencial_plug`. `retryable` só em pending/timeout/429/503.

`PERFIL_TETO` inclui `details` com a fase em que o orçamento parou,
`queriesUsadas`, `queriesLimite`, `retomavel: true` e as colunas/JOINs ainda sem perfil completo.
A próxima chamada de `enriquecer=completo` pula o que já tem tipo+formato ou cardinalidade.
Essas pendências orientam um novo treinamento, confirmação de cardinalidade ou
ajuste do SQL; não autorize publicação com base apenas nesse aviso.
