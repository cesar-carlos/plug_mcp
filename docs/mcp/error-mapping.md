# Mapeamento de erros

Envelope das tools:

```json
{
  "success": false,
  "error": {
    "code": "PERMISSION_DENIED",
    "message": "O client_token não cobre uma ou mais tabelas deste SQL.",
    "hint": "Peça um client_token que inclua essas tabelas.",
    "retryable": false,
    "retryAfterMs": null
  }
}
```

Não vaze stack, SQL interno do MCP, senha, `client_token` ou token MCP.

## Hub / RPC

| Origem                        | `code`                                      | hint típico                                                                                                                                                                  |
| ----------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JSON-RPC `-32001`             | `MISSING_CLIENT_TOKEN`                      | Configure o `client_token` no acesso.                                                                                                                                        |
| `-32002` + "classification"   | `INVALID_SQL`                               | Agente não classificou o SQL. Conferir FROM e o dialeto (`atualizar_dialeto` se for SQL Server). Não é token revogado. O hint de `consultar_dados` cita as tabelas enviadas. |
| `-32002` (sem classification) | `ACCESS_REVOKED`                            | client_token revogado ou sem permissão.                                                                                                                                      |
| JSON-RPC `-32009`             | `INVALID_SQL`                               | SQL recusado pelo dialeto do agente.                                                                                                                                         |
| HTTP 403 Client inativo       | `CLIENT_NOT_ACTIVE` / `AGENT_ACCESS_DENIED` | Ativar o Client; **não** tratar como senha errada.                                                                                                                           |
| HTTP 429                      | `RATE_LIMITED`                              | `Retry-After`.                                                                                                                                                               |
| HTTP 503                      | `AGENT_UNAVAILABLE`                         | Agente offline; retry.                                                                                                                                                       |
| HTTP 401                      | `USER_AUTH_EXPIRED`                         | `withHubAuth` invalida o JWT, reloga e **repete a operação uma vez**. Se a senha do cofre falhar: `CREDENTIAL_STALE`.                                                        |
| abort HTTP                    | `PLUG_SERVER_TIMEOUT`                       | Retryable.                                                                                                                                                                   |
| JSON-RPC `-32008`             | `QUERY_TIMEOUT`                             | Query estourou o timeout do agente; retry ou reduza o SQL.                                                                                                                   |
| HTTP 5xx / RPC genérico       | `PLUG_SERVER_ERROR`                         | Falha no hub; veja hint. Retry se `retryable`.                                                                                                                               |

## Domínio

| `code`                                   | Quando                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UNAUTHENTICATED`                        | Sem Bearer (fora do bootstrap) ou token inválido                                                                                                                                                                                                                                                                                                                                                                                                                |
| `ALIAS_DESCONHECIDO`                     | Qualificador de coluna/JOIN não resolve para FROM/JOIN deste SELECT                                                                                                                                                                                                                                                                                                                                                                                             |
| `COLUNA_AMBIGUA`                         | Coluna sem alias com mais de uma tabela no SELECT                                                                                                                                                                                                                                                                                                                                                                                                               |
| `PACOTE_INCOMPLETO`                      | Skill sem fatos confirmados no grafo, JOIN sem cardinalidade ou métrica sem tipo na publicação                                                                                                                                                                                                                                                                                                                                                                  |
| `MULTI_SKILL_PARAMS`                     | Mesmo nome de param com tipo/obrigatoriedade diferentes ao cruzar skills                                                                                                                                                                                                                                                                                                                                                                                        |
| `METADATA_CONTRATO`                      | Paginação sem `pagination` do agente; não assumir fim dos dados                                                                                                                                                                                                                                                                                                                                                                                                 |
| `VALIDATION_ERROR`                       | Parâmetro ausente/inválido; `criar_skill`/`atualizar_skill` com tabelas fora do grafo; `validar_skill` com params sem descrição; `publicar_skill`/`remover_skill` sem checklist ou sem `confirmadoPeloUsuario`; valor incompatível com `tipo`; `GROUP BY` acima do teto de expressões; paginação (`page`+`page_size`) sem `ORDER BY` no SELECT externo ou com `TOP`/`LIMIT`/`OFFSET`/`FETCH`/`FIRST`/`START AT` no SQL; `pergunta` ausente em `consultar_dados` |
| `ACESSO_NOT_FOUND`                       | `acessoId` de outro usuário                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `AGENT_ACCESS_PENDING`                   | Pedido ainda pending                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `DIALECT_CONFLICT`                       | Segundo dialeto no mesmo `agentId` sem `atualizar_dialeto`                                                                                                                                                                                                                                                                                                                                                                                                      |
| `CONFLICT`                               | Acesso/skill duplicado                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `CREDENTIAL_STALE`                       | Senha do Client no cofre recusada no login (depois do 401 + retry)                                                                                                                                                                                                                                                                                                                                                                                              |
| `PERMISSION_DENIED`                      | Policy do `client_token`                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `USER_AUTH_EXPIRED`                      | JWT do Client recusado mesmo após o retry único de `withHubAuth`                                                                                                                                                                                                                                                                                                                                                                                                |
| `INVALID_SQL`                            | `SELECT *` (também aninhado), mutação, segundo comando, expressão sem AS, coluna sem qualificador em JOIN, JOIN sem igualdade no `ON`; SQL que o plug_agente não classifica (`-32002` + classification) — não é token revogado                                                                                                                                                                                                                                  |
| `SKILL_NOT_FOUND` / `ANOTACAO_NOT_FOUND` | Id inexistente neste `agentId`. Hint lista nomes próximos quando houver.                                                                                                                                                                                                                                                                                                                                                                                        |
| `SKILL_NOT_PUBLISHED`                    | Skill em rascunho/validada em `consultar_dados`                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `SKILL_GAP`                              | `buscar_contexto` sem skill publicada capaz (payload, não throw)                                                                                                                                                                                                                                                                                                                                                                                                |
| `DIALECT_UNSUPPORTED`                    | SQL livre em `firebird` (só consulta exemplo)                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `TABELA_FORA_DO_ESCOPO`                  | SQL da IA cita tabela fora do pacote publicado. Hint lista nomes próximos.                                                                                                                                                                                                                                                                                                                                                                                      |
| `COLUNA_FORA_DO_ESCOPO`                  | Coluna fora do catálogo da tabela no escopo. Hint lista colunas disponíveis.                                                                                                                                                                                                                                                                                                                                                                                    |
| `JOIN_DESCONHECIDO`                      | JOIN que não casa com relacionamento conhecido. Use `confirmar_relacionamento`.                                                                                                                                                                                                                                                                                                                                                                                 |
| `CONSULTA_SEM_RECORTE`                   | SQL livre sem WHERE e sem agregação (janela `OVER` conta como agregação)                                                                                                                                                                                                                                                                                                                                                                                        |
| `ESCOPO_FILTRO_AUSENTE`                  | Acesso tem empresa/filial default e o SQL não recorta a coluna correspondente                                                                                                                                                                                                                                                                                                                                                                                   |
| `RATE_LIMITED`                           | Teto HTTP ou por tool                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `QUERY_TIMEOUT`                          | Timeout da query no agente                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `PLUG_SERVER_ERROR`                      | Erro genérico do hub                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `INTERNAL_ERROR`                         | Falha inesperada no MCP                                                                                                                                                                                                                                                                                                                                                                                                                                         |

Avisos (não são throw): `LITERAL_TEXTO` (literal em WHERE/HAVING — prefira `:param`), `PLACEHOLDER_ESCOPO` (grafo tem coluna empresa/filial e o SQL não usa `:empresa`/`:filial`), `PERFIL_QUERY_FALHOU` / `PERFIL_TETO` no treino/validação completo, `CATALOGO_TIPOS_AMBIGUOS` em `mapear_tabela`, `PERFIL_AUSENTE` em `obter_skill`, `CACHE` (dataDoResultado vs servidoEm).
